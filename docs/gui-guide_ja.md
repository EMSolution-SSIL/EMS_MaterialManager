# GUIガイド

[English](gui-guide.md)

## 材料ツリー

左ペインは `source -> family -> material` のツリーです。Material ID は内部識別子であり、ツリーにはソース、ファミリー、材料名を表示します。これにより長いIDでリストが見づらくなることを防ぎます。

検索欄では名称、ID、メーカー、タグで絞り込めます。ソースとファミリーは折り畳めます。

## 材料の作成と編集

- **New Material** は材料タイプ選択画面を開きます。選択したテンプレートによって、必須、推奨、任意のプロパティが決まります。
- **Edit Material** は書き込み可能な `User` 材料を編集状態にします。
- **Edit as User Copy** は、読み取り専用の参照材料を `User` に複製します。元の参照レコードは保持されます。
- **Duplicate**、**Import**、**Export**、**Delete** はFileメニューと対応するボタンから実行できます。

参照レコードは既定で読み取り専用です。管理者は `--admin-edit-reference` を付けて起動すると、参照レコードを修正できます。参照レコードの削除は管理者モードでも無効です。

```powershell
ems-material-manager --library-root .\materials --admin-edit-reference
```

## プロパティカタログ

プロパティペインでは、未設定の既知プロパティも表示します。展開可能なグループにより、等方性の基本パラメータと、任意の異方性・複素パラメータを区別します。

- **Electric Property:** 導電率、比誘電率、複素比誘電率
- **Magnetic Property:** 比透磁率、B-Hカーブ、方向別B-Hカーブ、鉄損係数、複素比透磁率
- **Manufacturing:** 密度、および該当する場合の電磁鋼板厚さ

各スカラー／カーブプロパティにはノート欄があります。鉄損係数には、代表磁束密度などの測定条件を記録してください。

## カーブエディタ

カーブプロパティをダブルクリックするか **View Property** を使用すると、表とグラフを備えたエディタを開きます。B-Hカーブは点として編集でき、線形または対数軸で表示できます。方向別のX/Y/Zカーブは任意項目であり、既定では折り畳まれています。
