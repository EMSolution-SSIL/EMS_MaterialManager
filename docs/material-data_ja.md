# 材料データ管理

[English](material-data.md)

## マネージャルート

マネージャルートには、データソースの明示的な許可リストを置きます。

```text
materials/
  manager.config.json
  _catalog/
  User/
    source.config.json
  IEEJ/
    source.config.json
```

- `manager.config.json` は有効にするソースフォルダと既定の書き込み先を設定します。
- 各 `source.config.json` は、そのソースから表示する材料ファイルを列挙します。
- `_catalog` は、材料タイプ、プロパティ定義、単位、要件、テンプレートを定義します。

これらの設定ファイルに列挙されていないフォルダやファイルは無視されます。これにより、候補、非公開、または使用頻度の低いデータをマネージャルートの近くに置いても、GUIに表示しないようにできます。

## ソース

通常は `User` が書き込み可能です。新規作成、インポート、複製、プロジェクト材料の登録はここに追加されます。参照ソースは通常読み取り専用であり、変更する前に `User` にコピーしてください。

## 交換形式

Canonical JSON は、持ち運び可能な材料レコード形式です。GUIはJSONのインポート／エクスポートに対応し、表形式のカーブデータはカーブエディタで編集できます。利用者は、適用されるデータライセンスの範囲で、出力したJSONやCSVを研究用途や他ツール向けに変換できます。

## データ品質

各レコードには、出所、出典URL、バージョン、単位、測定条件を保存してください。鉄損係数など、代表磁束密度、周波数、温度、試験片条件にのみ適用される値にはノートを付けます。

材料データセットを配布する前に、[ライセンスとデータ来歴](licensing_ja.md) を確認してください。
