# リリースノート

[English](release-notes.md)

## 0.1.0 — 2026-09-22

- 製品名称を **EMS Material Manager** に統一しました。
- Python配布パッケージを `ems-material-manager`、主APIクラスを `MaterialManager` に統一しました。
- 設定ルートファイルを `manager.config.json`、eMotorSolutionの設定を **Material Manager root** に変更しました。
- インストール、GUI操作、EMSolution API、eMotorSolution連携、材料データ管理、ライセンスに関する公開ドキュメントを追加しました。
- 材料テンプレート、プロパティカタログ編集、B-Hカーブ編集、ソース制御、eMotorSolution連携、EMSolution `input.json` 連携のPoC機能を完成させました。
- 英語版と日本語版の利用者向けドキュメントを公開しました。
