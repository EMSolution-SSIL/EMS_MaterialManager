# Release Notes

## Unreleased — 0.1.0 pre-release

- Standardized the product name as **EMS Material Manager**.
- Renamed the Python distribution to `ems-material-manager` and the primary API class to `MaterialManager`.
- Renamed the configured-root file to `manager.config.json` and the eMotorSolution setting to **Material Manager root**.
- Added public documentation for installation, GUI operation, EMSolution API use, eMotorSolution integration, material-data management, and licensing.

The first public preview release will be versioned separately after repository, license, data-provenance, and packaging checks are complete.
