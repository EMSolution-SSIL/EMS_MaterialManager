# ライセンスとデータ来歴

[English](licensing.md)

## コードとデータは別です

リポジトリ直下のライセンスは、EMS Material Managerのコードだけに適用されます。材料データ、文献から抽出したデータ、顧客から提供されたデータに自動的に適用されるものではありません。

ソースコードは PolyForm Perimeter License 1.0.1 で提供されます。リポジトリ直下の `LICENSE` と `NOTICE` を確認してから、コードを使用または再配布してください。

## データセットごとの必要事項

配布する各材料データセットには、少なくとも次を記載してください。

- 提供者と一次出典URL
- 著作権表示と適用されるライセンスまたは利用規約
- 取得日とデータセットバージョン
- 商用利用、改変、再配布の可否
- 必要な帰属表示
- EMSolution-SSIL が行った単位変換や補間などの変換内容

推奨する配置は、人が読む説明を `data/<dataset>/README.md`、機械可読な来歴とファイルハッシュを `data/<dataset>/manifest.json` とする形式です。

## 第三者・公開データ

公開されていることだけでは再配布権は得られません。IEEJなどの第三者材料データは、想定する再配布を利用条件が明示的に許可するまで、公開リポジトリやパッケージに含めないでください。再配布が許可されていない、または不明な場合は、インポータ、出典URL、利用者向け手順のみを配布します。

## 保護対象データ

契約、顧客、高付加価値のデータセットは公開コードリポジトリには含めません。それぞれの認可・ライセンス条件に基づいて別途提供します。暗号化と鍵管理は、元データのライセンス確認の代わりにはなりません。
